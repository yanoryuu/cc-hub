# 委譲プロンプトのテンプレート

サブエージェントは会話履歴を持たない。以下を埋めて自己完結させる。必要な文脈は抜粋して渡し、全部は渡さない。

```
【目的】<何を達成するか 1〜2文>

【背景】<プロジェクト名・技術スタック・このタスクに関係する仕様や設計の要点。
        参照すべき CLAUDE.md / docs / 既存コードのパスがあれば明記>

【作業環境】専用の git worktree で作業中。コミット・push はしない。
           パッケージの追加(npm install 等)はしない。<必要なら理由と例外を書く>

【担当範囲】<触ってよいファイル/ディレクトリ>
【触らない範囲】<他エージェント担当・共有ファイル。必要な変更は報告に書く>

【規約】<コーディング規約・命名・テスト方針など、該当するものだけ>

【完了条件】
- <具体的・検証可能な条件>
- <ビルド/型チェック/テストのコマンドと期待結果>

【報告形式】日本語・〜800字。1) 結論 2) 変更ファイル一覧 3) 実行した検証と結果 4) 残作業・手動対応 5) 懸念点
```

## 書き方のコツ
- 「調べて」ではなく「何を判断するために何を調べるか」を書く
- 読み取り専用タスクは明記する(「ファイルを変更しない」)
- 出力は要約を指定し、長いログやファイル全文を返させない
- 調査系は Explore の探索度合い(medium / very thorough)を指定する
- 成功条件はコマンドで確認できる形にする(例: `npm test` が通る)
